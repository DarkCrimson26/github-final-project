# Simple Interest Calculator

A Bash calculator that computes simple interest from a principal amount, annual interest rate, and time period in years.

## Inputs

- Principal amount
- Annual interest rate as a percentage
- Time period in years

## Calculation

Simple interest = principal × annual rate × time / 100.
The script uses integer arithmetic.

## Usage

Run `bash simple-interest.sh` and enter the three values when prompted.

## Example

Principal: 1000; annual rate: 5%; time: 2 years.
Simple interest: 100.
